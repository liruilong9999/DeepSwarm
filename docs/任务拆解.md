# DeepSwarm 首版任务拆解

本文以《设计.md》为唯一产品契约，以《DeepSeekAPI完整开发手册-官方文档不许修改.md》为 DeepSeek API(应用程序编程接口) 语义基线。官方手册保持只读。

## 任务与依赖

| 任务 | 范围 | 依赖 | 验证方式 | 可并行 |
| --- | --- | --- | --- | --- |
| TASK-001 | workspace、Schema、默认配置 | 无 | `cargo metadata`、Schema 固定样例 | 否 |
| TASK-002 | DeepSeek 客户端、SSE(服务器发送事件) 解析、错误映射 | TASK-001 | 客户端契约测试 | 是 |
| TASK-003 | DeepSeek Mock(模拟) 服务 | TASK-002 | 同一 fixture 同时通过客户端与服务端 | 否 |
| TASK-004 | Agent(智能体) 生命周期、Fork、继承、取消、软预算 | TASK-001 | 状态机、CAS(比较并交换)、并发测试 | 是 |
| TASK-005 | DSL(领域专用语言)、变量绑定、数据源、断言 | TASK-001 | 预检零调用、运行时绑定与断言测试 | 是 |
| TASK-006 | 录制回放、脱敏报告、租约结果协议 | TASK-005 | 哈希、去重、脱敏、保留期测试 | 否 |
| TASK-007 | 工具注册表、策略拦截、12 个模拟工具 | TASK-004 | Schema、拒绝顺序、Run 隔离测试 | 是 |
| TASK-008 | WASM(WebAssembly，网页程序集) 插件宿主 | TASK-001 | 版本、能力、负载和超时测试 | 是 |
| TASK-009 | CLI(命令行界面) 的 run/mock/record/replay | TASK-002～TASK-008 | 端到端命令测试 | 否 |
| TASK-010 | 模糊测试、性能基准、CI(持续集成) | TASK-002～TASK-009 | 固定变异次数与基准报告 | 否 |

## 智能体所有权

| 智能体 | 首轮所有权 | 禁止修改 |
| --- | --- | --- |
| 主智能体 | 根配置、Schema、文档、`deep-swarm-tools`、最终集成 | 官方 API 手册 |
| 协议智能体 | `deep-swarm-client`、`deep-swarm-mock-server` | Agent、核心、工具代码 |
| Agent 智能体 | `deep-swarm-agent` | 客户端、核心、工具代码 |
| 核心智能体 | `deep-swarm-core` | 客户端、Agent、工具代码 |

第二轮在首轮合并后重新分配 CLI、插件、模糊测试、基准和独立审查。任何共享接口变更由主智能体统一决定。

## 完成定义

- 设计中的首版验收点均有代码和可运行测试。
- `cargo fmt`、`cargo clippy`、`cargo test` 全部通过。
- 官方 API 手册未修改，文档、Schema、实现与测试一致。
- 真实 API、真实工具和高负载测试均保持显式启用，不在默认测试中产生外部副作用。
