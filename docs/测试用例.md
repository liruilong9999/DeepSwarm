# DeepSwarm 首版测试用例

## 协议与 Mock 服务

- 非流式响应覆盖普通内容、思考内容、工具调用和 Token(令牌) 用量。
- SSE(服务器发送事件) 覆盖空行、保活注释、顺序分片、`[DONE]`、非法 JSON 和提前断开。
- HTTP 400、401、402、404、422、429、500、503 映射到设计指定错误；只有临时错误最多尝试三次。
- Mock(模拟) 服务与客户端复用同一模型类型和 fixture(测试夹具)。

## Agent 与并发

- 每条合法生命周期迁移成功，每条非法迁移返回 `InvalidState`，重复取消与终态查询幂等。
- Fork 后私有状态隔离；继承模式只共享声明项；子 Agent 权限只能收窄。
- 两个写入使用相同版本时只有一个 CAS(比较并交换) 成功。
- Session(会话) 取消传播到全部 Agent，每个 Agent 只发出一次完成事件。
- 有界邮箱满时返回 `ResourceExhausted`，测试运行不跨 `await` 持锁。

## DSL、断言与数据源

- YAML 与 JSON 使用同一 Schema；未知字段、未知版本、重复步骤、前向引用、保留命名空间和总步骤超限在零调用时失败。
- 单占位符保留 JSON 类型；字符串内非字符串插值失败；跳过步骤的输出引用返回 `UnresolvedOutput`。
- `exists`、`json_schema`、`contains`、`regex`、`similarity`、`metric` 均有通过和失败样例。
- CSV 重复表头、列数不符、非法 UTF-8，以及 JSONL 非对象、路径穿越和符号链接逃逸在零调用时失败。
- 固定时钟下负载阶段、权重、最近秩 P95(第 95 百分位延迟) 和样本隔离可重现。

## 工具、安全与隔离

- 12 个模拟工具名称唯一、Schema 有效且无外部副作用；未知工具返回 `NotFound`。
- 拦截顺序固定为参数校验、策略门禁、取消检查、故障注入、执行、结果分类。
- 两个 Run(测试运行) 的同名自定义工具与授权句柄互不串用，构建后注册表冻结。
- 真实能力默认拒绝；路径穿越、符号链接逃逸、未授权命令和网络目标被策略拒绝。

## 录制、分布式与报告

- 无敏感录制可在断网环境精确回放；版本、事件顺序、参数或哈希变化在首个差异处失败。
- 敏感 Schema 字段、密钥模式和授权句柄在落盘前返回 `RecordingUnsafe`。
- 租约过期后递增 attempt(尝试次数) 并更换租约 ID；旧租约、重复结果和错误哈希不改变汇总。
- 报告 JSON、JUnit XML 与 HTML 中不出现固定或随机敏感原值，输出按 4 KiB/64 KiB 规则截断。
- 可注入时钟下，报告在保留期边界前保留、边界时删除。

## 插件、CLI 与性能

- 兼容 WIT(WebAssembly 接口类型) 插件执行生命周期；不兼容版本、未知能力、超负载和超时被拒绝。
- `run`、`mock`、`record`、`replay` 命令具有成功、参数错误和取消路径。
- 性能场景 A、B 分开运行并记录环境；环境不符时不误判产品失败。
- 三个模糊测试目标对非法输入不得 panic(恐慌)、超时或越权。
